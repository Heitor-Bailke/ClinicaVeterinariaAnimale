# Animale — Clínica Veterinária

Landing page institucional responsiva criada para a **Animale Clínica Veterinária**, com foco em apresentar os serviços, fortalecer a marca e facilitar o contato dos tutores pelo WhatsApp.

## Sobre o projeto

O site reúne informações da clínica e do hospital veterinário 24 horas em uma experiência visual acolhedora, moderna e fácil de navegar. A página foi pensada para funcionar bem em computadores, tablets e celulares.

## Funcionalidades

- Design responsivo para diferentes tamanhos de tela
- Seções institucionais sobre a Animale, serviços e especialidades
- Carrossel de serviços com controles de navegação
- Formulário de contato que prepara uma mensagem organizada no WhatsApp
- Escolha entre as duas unidades de atendimento
- Telefones e links de rota no Google Maps para cada unidade
- Menu mobile, animações sutis e botões de contato rápido
- Links para WhatsApp e Instagram

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts

## Contato e localização

O formulário envia o atendimento diretamente para o WhatsApp, levando também o assunto, a unidade escolhida e os dados preenchidos pelo tutor. Os links de mapa direcionam para as unidades da Animale em Colatina — ES.
